| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| **F**   | **Функциональные (Functionality)**     |              |
|     | Пользователь видит все доступные продукты на сайте с актуальной инф-ей  на сайте и ИБ  |     |
|     | Возможность СМС информирования  |              |
|     | Более гибкая работа со ставками для сотрудников отделов кредитов и депозитов. (Перенос ф-ий из EXCEL в АБС)      |              |
|     | Перенос процессов согласования в АБС  |              |
|     | Возможность подачи заявки на кредит на сайте |              |
|     | В ИБ переодически должен происходить скоринг клиента, результат должен предлагаться клиенту |              |
| **U**   | **Удобство использования (Usability)** |              |
|     | Менеджер сам звонит клиенту и подготавливает данные           |              |
|     | Возможность подачи заявки на кредит на сайте |
|     | СМС информирование  |              |
|     | Сотрудник отделения должен иметь возможность работать с предодобренной заявкой на кредит |              |
|     | СМС информирование по всем статутсам |              |
| **R**   | **Надёжность (Reliability)**           |              |
|     | Использование механизма шифрования трафика         |  Для сайта и ИБ  |
|     | Интернет-банк должен работать на двух нодах в разных ЦОДах и быть защищен от сбоев одного ЦОД |              |
|     | Критические операции требуют СМС подтверждений  |              |
|     | Необходимость резервного копирования  | Обязательная вещь всех критических систем |
| **P**   | **Производительность (Performance)**   |              |
|     | Отклик системы должен занимать миллисекунды   |              |
|     | Достпуность сервисов 24/7 и доступность 99.9 |              |
|     | Необходимость кэширования справочных данных |              |
|     | Для ускорения скоринга по новым клиентам необходимо кэшировать данные бюро кредитных историй |              |
| **S**   | **Поддерживаемость (Supportability)**  |              |
|     | Возможные новые техн-гии должны быть совместимы с существующими  |              |
|     | В банке должны быть спец-ты которые могут поддерживать исп. техн-гии                                |              |
|     | Предусмотреть обязательное ведение док-ии, и включение это в процесс проектирования-разработки вцелом   |              |
| **+R**  | **+ Ограничения (Restrictions)**       |              |
|     | Использование MS Sql и Oracle |              |
|     | При необходимости асинхронности использовать Kafka |              |
|     | Микросервисную арх. использовать только в ф-ле открытия депозитов        |              |
|     | Необходимо использовать цвета банка |              |
|     | Избегать прямой работы интернет банка с АБС |              |
|     | АБС масштабируется только вертикально изза БД |              |
|     | Заявки из АБ в КК могут передаваться только раз в сутки |              |
|     | Предрасчет кредита не должн на прямую обращаться в скоринг систему |              |
